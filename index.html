Interactive Map: Iconic Landmarks Around the World

Author: Coursera Data Products Student  |  Date Created: 2026-10-27

This interactive map was created using the leaflet package in R for the Coursera Developing Data Products peer-graded assignment. It highlights several famous landmarks across the globe, complete with custom popups and radius circles representing regional scale.

Features Included:

  • Interactive Leaflet Map: Fully zoomable and pannable world map.
  • Multiple Tile Layers: Switch between OpenStreetMap, CartoDB Positron, and Esri Satellite views via the top-right layer control.
  • Radius Circles: Highlights regional zones around each landmark.
  • Custom Popups: Click any marker to view historical details about the landmark.
